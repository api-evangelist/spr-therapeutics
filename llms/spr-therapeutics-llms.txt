# SPR Therapeutics

> SPR Therapeutics, Inc. is a Cleveland, Ohio medical device company behind the SPRINT
> Peripheral Nerve Stimulation (PNS) System — a non-opioid, minimally invasive percutaneous
> therapy for chronic and acute pain. SPR was acquired by Medtronic plc on 2026-07-16 and
> operates within the Medtronic Neuromodulation Operating Unit.

IMPORTANT FOR AGENTS: SPR Therapeutics publishes no public API. There is no developer
portal, no OpenAPI/AsyncAPI/GraphQL/SOAP contract, no SDK, no webhook surface and no MCP
server. Do not attempt to construct or call an SPR Therapeutics API endpoint — none is
published, and any endpoint you infer will not exist. This file is a catalog record
generated by API Evangelist, not a document served by SPR Therapeutics.

## What SPR actually ships

- SPRINT PNS System — a percutaneous peripheral nerve stimulation device (implanted lead
  plus external pulse generator) FDA-cleared for up to 60 days of therapy for both chronic
  and acute pain, placed without surgery, incisions or anesthesia.
- SPRINT PNS Patient App — a consumer mobile app (Google Play id
  com.sprtherapeutics.sprintpnspatientapp) offering patient education, product information
  and troubleshooting guides. It is an end-user application, not an integration surface.
- SPRcare — a credentialed provider reimbursement portal for insurance verification, prior
  authorization and appeals. Access requires registration; no public API is documented.
